# Univer KSTU — вход через Platonus

## Что внутри
- `index.html` — сама Mini App (фронт), сейчас с формой входа.
- `api/login.js` — логинится в Platonus от имени студента, отдаёт временный `session` (без пароля).
- `api/gpa.js` — GPA + studentID/имя студента (используется сразу после входа).
- `api/schedule.js` — реальное расписание из Platonus.
- `api/grades.js` — оценки/успеваемость по предметам (журнал).
- `api/_lib/platonus.js` — общие хелперы (сборка заголовков, декодирование сессии).

## Как задеплоить (Vercel)

1. Зайди на https://vercel.com, войди через GitHub.
2. Создай новый репозиторий на GitHub, залей туда содержимое этой папки целиком
   (`index.html`, `api/`, `package.json`).
3. На vercel.com → **Add New → Project** → выбери этот репозиторий.
4. Framework Preset — оставь **Other**. Никаких переменных окружения не нужно.
5. Нажми **Deploy**. Через минуту получишь адрес вида
   `https://твой-проект.vercel.app`.
6. Проверь: открой этот адрес в браузере, попробуй войти своим логином/паролем от Platonus —
   должно появиться расписание, GPA и оценки.
7. В BotFather (Telegram) укажи этот URL как адрес Mini App вместо старого.

## Важно про безопасность

- Пароль студента отправляется один раз, напрямую в Platonus, по HTTPS.
  Он нигде не логируется и не сохраняется — используется и тут же забывается.
- Вместо пароля клиенту возвращается `session` — обёртка над `sid`/`token`/`cookie`,
  которые Platonus сам выдаёт после входа. Это то же самое, что обычная веб-сессия сайта.
- `session` хранится в `localStorage` браузера — это удобно (не надо логиниться заново
  при каждом открытии), но при компрометации устройства даёт доступ к аккаунту,
  пока сессия жива на стороне Platonus. Кнопка «Выйти» в приложении просто стирает
  `session` локально — сама сессия на Platonus продолжит жить, пока не истечёт сама
  или пока студент не сменит пароль / не завершит сессии в настройках Platonus.
- Если бэкенд отдаёт `401 session_expired` — фронт сам разлогинивает и просит войти заново.

## Что может потребовать доработки

- Формат ответа `/journal/{year}/{term}/{studentID}` может отличаться для других
  студентов/специальностей — если увидишь ошибку на вкладке «Оценки», пришли мне
  реальный ответ и поправим парсинг.
- Раздел «УМКД» и старые фейковые «Экзамены» пока остались как заглушки — реальных
  эндпоинтов под них ещё не искали.
