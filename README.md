# UniLink

Веб-приложение и Telegram Mini App для студентов КарТУ: расписание и учебные данные из Platonus, личные сообщения через Supabase. На iPhone и Android приложение можно добавить на главный экран.

[Открыть UniLink](https://univerapp.vercel.app/) · [Документация](docs/README.md) · [Развёртывание](docs/deployment.md)

## Возможности

- **Расписание:** недели и дни, преподаватели и аудитории, текущая пара и её прогресс, ближайшее занятие.
- **Расписание для друга:** карточка выбранного дня, отправка PNG через системное меню (в том числе в WhatsApp), скачивание и выбор показа преподавателей. Картинка создаётся на устройстве; если отправка файлов недоступна, можно сохранить её отдельно.
- **Оценки:** показатели журнала, GPA и история семестров.
- **Что изменилось:** история изменений показателей оценок, времени, преподавателей и аудиторий пар; счётчик непрочитанных изменений и сравнение «было → стало». История хранится на устройстве, первая загрузка создаёт исходный снимок.
- **Без интернета:** последнее сохранённое расписание с аудиториями и экзамены с датой сохранения. Для открытия после перезапуска нужен ранее выполненный вход с «Запомнить меня»; переписки требуют подключения.
- **Профиль:** учебные сведения, академический календарь, транскрипт, расписание экзаменов и итоги семестра UniLink Recap.
- **УМКД:** дисциплины, просмотр и скачивание PDF.
- **Сообщения:** поиск пользователей, личные переписки, непрочитанные, индикатор набора, статус присутствия и профиль собеседника.
- **Telegram:** привязка аккаунта и уведомления бота с переходом в переписку.
- **Оформление:** светлая и тёмная темы, акцентные цвета, адаптивный фон, погода и качество воздуха.
- **Повторное открытие:** кэш учебных данных, публичная оболочка для открытия без сети и восстановление запомненного входа с ключом устройства.

Групповых чатов, вложений и звонков нет. Сообщения не имеют сквозного шифрования. При включённом «Запомнить меня» завершённая сессия Platonus обновляется по защищённому пакету устройства в пределах 30 дней. Смена пароля, очистка хранилища или истечение пакета потребуют нового входа.

## Технологии

Интерфейс — HTML, CSS и JavaScript без сборщика. API — JavaScript-функции Vercel на Node.js. База — Supabase PostgreSQL, доступ с сервера через REST/RPC. Тесты используют встроенный `node:test` и PostgreSQL в PGlite.

## Быстрый старт

Рекомендуется Node.js 24; минимальная заявленная версия — 22.

```sh
npm ci
npm run verify
```

Проверки не требуют настоящих паролей, доступа к Platonus или рабочей базе. Чтобы запустить весь проект локально, установи официальный Vercel CLI, создай `.env.local` по [.env.example](.env.example) и выполни `vercel dev`. Открытие `index.html` как файла или обычный статический сервер не запускают `/api`.

| Команда | Назначение |
| --- | --- |
| `npm run verify` | Проверка проекта и все тесты |
| `npm run check` | Синтаксис, ресурсы, ссылки документации, manifest и service worker |
| `npm test` | Все тесты |
| `npm run test:api` | API и защита входа |
| `npm run test:ui` | Браузерная логика и регрессии интерфейса |
| `npm run test:database` | Миграции, SQL-функции и права доступа |

GitHub Actions выполняет проверки при push и pull request. Публикация остаётся в Vercel.

## Настройка сервера

| Переменная | Назначение |
| --- | --- |
| `SUPABASE_URL` | URL проекта базы, обязательна |
| `SUPABASE_SERVICE_ROLE_KEY` | Серверный ключ Supabase, обязательна; не `anon` / `publishable` |
| `UNILINK_SESSION_KEY` | 32 случайных байта в виде 64 hex-символов, обязательна |
| `TELEGRAM_BOT_TOKEN` | Токен бота, только для Telegram |
| `TELEGRAM_BOT_USERNAME` | Имя бота для ссылки открытия приложения |
| `TELEGRAM_APP_SHORT_NAME` | Только для именованного Mini App |

Для нового проекта выполни [SQL-миграции](supabase/migrations) по порядку **001 → 006**. Supabase нужен также для общего ограничения попыток входа: без базы и миграции 006 вход возвращает 503. Значения переменных задаются только на сервере.

В Vercel выбери **Other** и оставь корень репозитория. Команда сборки уже задана в `vercel.json`: она автоматически маркирует опубликованную версию для уведомлений об обновлении. Функции настроены на **Frankfurt (`fra1`)**; базу размещай рядом. Полный порядок — в [инструкции развёртывания](docs/deployment.md).

## Вход и данные

Пароль используется только для входа в Platonus и не сохраняется. Основной доступ идёт через зашифрованную HttpOnly cookie. При «Запомнить меня» устройство дополнительно сохраняет зашифрованный пакет сессии и ключ восстановления (IndexedDB в браузере, SecureStorage в поддерживаемых версиях Telegram): если cookie потеряется при закрытии PWA, сервер проверит подпись устройства и восстановит её. Максимум — 30 дней от исходного входа; без этой опции — браузерная сессия до 8 часов.

После обновления с версии, где был только cookie-вход, нужно один раз войти заново с включённым «Запомнить меня». Новые SQL-миграции или переменные для восстановления не нужны. Подробности — в [описании защиты](docs/security.md).

Учебные данные могут оставаться в локальном кэше до выхода. Переписки хранятся в Supabase; сервер проверяет участников каждого запроса. Секретный ключ базы никогда не передаётся интерфейсу.
