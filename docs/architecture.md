# Архитектура UniLink

## Поток данных

Браузер → серверные функции `/api` → Platonus или Supabase. Интерфейс не получает сервисный ключ базы. Расписание, журнал, GPA, УМКД, календарь и транскрипт приходят из Platonus. Собственная база хранит переписки, профили, присутствие, Telegram-привязки, очередь уведомлений и лимиты входа.

Структура каталогов приведена в [README](../README.md); ниже — карта кода без дублирования дерева.

## Интерфейс

| Модуль в `assets/js/` | Ответственность |
| --- | --- |
| `appearance.js` | Тема, метаданные, особенности установленного iOS-приложения до отрисовки |
| `device-session.js` | IndexedDB, ключ устройства, восстановление при утрате cookie |
| `app.js` | Вход, общий экран, расписание, журнал, профиль, погода, УМКД и PDF |
| `academic.js` | Академический календарь и транскрипт |
| `chat.js` | Список переписок, история, отправка, профили, набор и присутствие |
| `wrapped.js` | Итоги семестра UniLink Recap |
| `navigation.js` | Возврат назад, история и жесты |
| `viewport-recovery.js` | Восстановление viewport после закрытия клавиатуры на iOS |
| `actions.js` | Разрешённые HTML-действия без inline-JavaScript |
| `updates.js` | Обновление публичной оболочки |
| `background.js` | Canvas-фон с учётом темы, экрана и энергосбережения |
| `sw.js` | Кэш только публичной оболочки |

Порядок подключения задаёт `index.html`. `device-session.js` должен загрузиться до `app.js`, а основной код — до чата и навигации. Стили разделены по экранам в `assets/css/`, общий масштаб текста задаёт `typography.css`. В `assets/icons/` оставлены действующие PNG и SVG-исходник `unilink.svg`.

## Серверные маршруты

| Маршрут | Назначение |
| --- | --- |
| `POST /api/login` | Вход в Platonus, лимит попыток, cookie и при необходимости пакет устройства |
| `GET /api/session` | Проверка основной cookie |
| `POST /api/session` | Challenge и восстановление по подписи устройства |
| `DELETE /api/session` | Очистка основной cookie |
| `GET /api/gpa` | GPA, личность и учебные сведения текущего студента |
| `GET /api/schedule` | Текущая или явно выбранная учебная неделя |
| `GET /api/grades` | Журнал выбранного семестра |
| `GET /api/umkd` | Дисциплины УМКД |
| `GET /api/umkd-file` | Авторизованный PDF |
| `GET /api/exams` | Личное расписание экзаменов из раздела Platonus v7 (`student/exam/initial/0/ru`) |
| `GET /api/calendar` | Разобранный HTML академического календаря |
| `GET /api/transcript` | Нормализованный личный транскрипт |
| `/api/chat` | Действия переписок, профилей, присутствия и Telegram |

Общие функции находятся в `api/_lib/`: `security.js` — cookie и шифрование, `device-session.js` — пакет и подпись устройства, `login-limit.js` — общие лимиты, `platonus.js` — заголовки upstream, `academic-documents.js` — разбор документов, `student-study.js` — учебные поля, `chat.js` и `telegram.js` — собственные сервисы.

Сессия устройства и обычная cookie имеют разное назначение шифрования. Пакет устройства не принимается другими API напрямую. Детали хранения и ограничений — в [описании защиты](security.md).

После загрузки основных учебных данных календарь и транскрипт запрашиваются в фоне. Модуль `academic.js` хранит их в памяти отдельно для каждого аккаунта на пять минут; открытие раздела использует готовые данные или уже начатый запрос. Предзагрузка не переключает экран, а при ошибке оставляет возможность повторить запрос при открытии. Выход очищает кэш и отменяет применение поздних ответов. Общий индикатор загрузки со стрелкой задаётся в `loading.js`; текстовые сообщения остаются для ошибок и действительно пустых разделов.

## Номер учебной недели

Без явных `year` / `term` / `week` поле `selectedWeek` Platonus иногда содержит значение, не совпадающее с текущей неделей. Для текущей недели используются `defaultSelectedWeek` / `activeWeekNumber`; с явными параметрами — `selectedWeek`.

В `buildScheduleEntryFromPlatonus` это различие сохраняется через `hadExplicitOverride`. Не смешивай выбранную для просмотра неделю с настоящей текущей: от этого зависят статус текущей пары и переход «Сегодня».

Недели начинаются с 1. Текущий предел задаётся `MAX_TERM_WEEKS` (15). Просмотренные недели кэшируются отдельно по учебному году, семестру и номеру. Поздние ответы старого аккаунта и неподходящие записи кэша отбрасываются.

## База и внешние сервисы

[Миграции 001–006](../supabase/migrations) применяются по порядку. Они создают таблицы и RPC, индексы, ограничения, RLS и права сервисной роли. Тесты выполняют SQL в PGlite. Open-Meteo обслуживает погоду и воздух; PDF.js загружается для просмотра PDF. Чат использует опрос, а не Supabase Realtime.
