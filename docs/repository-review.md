# Проверка репозитория — 17 ноября 2026

Проверены 113 файлов JavaScript, относительные импорты, HTML/CSS-ресурсы, ссылки документации, manifest, состав публичной оболочки и контрольные суммы сборки. Все 422 теста прошли: серверные маршруты, сессии, SQL-миграции, права чата, навигация, кэш, офлайн-просмотр и смена аккаунта. Рабочие npm-зависимости проверены через `npm audit --omit=dev`: известных уязвимостей на момент проверки нет. Проверки предыдущей публикации в GitHub Actions успешны; для новой версии CI запускается при push.

## Изменения

- Заголовок оценок объединён с верхней строкой: подпись и название справа от логотипа.
- Кольцо вращается целиком вокруг центра собственного SVG, без фиксированного центра внутреннего элемента в пикселях. При смене вкладки искусственная загрузка не запускается; при обновлении активной вкладки индикатор остаётся до завершения запроса и сбрасывается при ошибке.
- Навигация игнорирует изменения сообщений, индикаторов набора и прогресса, которые не меняют вложенный экран. Это убирает лишнее чтение геометрии DOM во время свайпов и опроса чата.
- Неизменившаяся история чата обновляет время проверки в памяти и не сериализуется в `sessionStorage` каждые 2,5 секунды. Контрольная запись — не чаще раза в минуту; реальные изменения сохраняются сразу.
- Canvas-фон приостанавливается при открытой экранной клавиатуре и возобновляется без скачка времени.
- Удалены неиспользуемые `weatherEmoji`, `openPdf`, старая анимация `tabIconPop`, таймеры искусственного обновления вкладок и лишние пустые строки CSS.
- Действующий PNG-мастер перенесён в `docs/branding/`, устаревший мастер удалён. Около 2,48 МБ исходников больше не попадают в публичную публикацию. Малые иконки прежних версий сохранены для совместимости со старыми установленными оболочками.
- README и документация приведены к текущим функциям: пересылка, выбор сообщений, предпросмотр переписок, API экзаменов, Speed Insights, preview и подготовка SDK при сборке.

## Границы проверки

Тесты используют обезличенные данные; реальные пароли и переписки не включались в проверочные файлы. Управление браузером Windows остановилось из-за невозможности надёжно определить URL окна Edge, поэтому визуальная проверка на настоящем ноутбуке в этой сессии не завершена. Системная клавиатура и завершение установленной PWA требуют отдельной проверки на устройстве. Численное ускорение FPS или времени загрузки не заявляется без сопоставимых измерений.
