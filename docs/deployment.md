# Размещение на Vercel

## Как задеплоить (Vercel)

1. Зайди на https://vercel.com, войди через GitHub.
2. Создай новый репозиторий на GitHub, залей туда содержимое этой папки целиком
   (включая `index.html`, `assets/`, `api/`, `package.json` и `vercel.json`).
3. На vercel.com → **Add New → Project** → выбери этот репозиторий.
4. Framework Preset — оставь **Other**. Учебные разделы работают без переменных
   окружения. Для чата подключи Supabase по [инструкции](chat-setup.md).
5. Нажми **Deploy**. Через минуту получишь адрес вида
   `https://твой-проект.vercel.app`.
6. Проверь: открой этот адрес в браузере, попробуй войти своим логином/паролем от Platonus —
   должно появиться расписание, GPA, оценки и список УМКД.
7. В BotFather (Telegram) укажи этот URL как адрес Mini App вместо старого.
