# Vercel: показатели скорости и предварительная версия

Speed Insights подключён через официальный пакет `@vercel/speed-insights` для обычного JavaScript. При сборке `scripts/prepare-speed-insights.mjs` подготавливает локальную браузерную копию SDK с лицензией. Next.js для этого не нужен.

В рабочей HTTPS-версии `assets/js/performance.js` загружает скрипт Vercel и включает отправку показателей скорости. В событиях остаётся только корневой адрес сайта: параметры ссылок на чаты, фрагменты и идентификаторы страниц удаляются. На localhost и при загрузке без сети отправка не включается.

Сводка доступна во вкладке Speed Insights проекта Vercel после посещений сайта. Добавление пакета не означает, что статистика уже накоплена.

`main` остаётся рабочей веткой. Для предварительной версии используется `codex/preview`: push в неё запускает отдельное развёртывание Vercel с тестовым URL. Проверенные изменения затем отправляются в `main`. В последующих изменениях эту же ветку можно обновлять перед публикацией.

Переменные окружения для Preview задаются отдельно в Vercel → Settings → Environment Variables. Рабочие секреты не копируются в репозиторий. Если подключение Platonus или чата недоступно только в предварительной версии, нужно проверить наличие соответствующих переменных в окружении Preview.

Описание механизма: [Vercel Preview Environment](https://vercel.com/docs/deployments/environments#preview-environment-pre-production), [Speed Insights](https://vercel.com/docs/speed-insights/quickstart).
